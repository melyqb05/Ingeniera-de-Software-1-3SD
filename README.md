Descripción

En la asignatura de Ingeniería de Software 1 he aprendido conceptos relacionados con el desarrollo de software, la identificación y análisis de requerimientos, la planificación de proyectos y el uso de herramientas para organizar y controlar el desarrollo de sistemas.

También he aprendido la importancia del control de versiones y el uso de Git y GitHub para gestionar proyectos, registrar cambios y mantener un historial del trabajo realizado.
